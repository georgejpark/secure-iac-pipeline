# Editable diagrams

Source files for both diagrams, in draw.io (diagrams.net) format.

| File | Diagram |
|---|---|
| `pipeline-flow.drawio` | Security pipeline control flow — the four gates |
| `system-architecture.drawio` | What runs where — runners, segments, state, deploys |

## Opening and editing

**Online, nothing to install:** go to <https://app.diagrams.net>, choose *Open Existing Diagram*,
and select the file.

**Desktop:** install the draw.io desktop app (`brew install --cask drawio`) and open the file
directly.

**VS Code:** install the *Draw.io Integration* extension (`hediet.vscode-drawio`), then click the
`.drawio` file in the explorer and it opens in an editor tab.

## After you edit, re-export the PNG

The documents embed PNGs from `../img/`, not these source files. If you change a diagram, export a
new PNG over the top of the old one so the docs pick it up:

**File → Export as → PNG…**, then:

| Setting | Value |
|---|---|
| Zoom | 200% |
| Border width | 10 |
| Background | White (untick *Transparent Background*) |
| Save as | `docs/img/pipeline-flow.png` or `docs/img/system-architecture.png` |

Then regenerate the Word documents and the deck so they carry the new image.

## How these are laid out

Everything uses **absolute coordinates with `parent="1"`** rather than nested containers. That makes
each shape independently draggable and keeps the XML readable, at the cost of the dashed zone
rectangles not moving their contents with them. Move a zone and you move only the frame.

Edges are attached with `source` and `target`, so they stay connected when you move the boxes they
join. Fixed exit and entry points (`exitX`/`entryX`) keep the routing tidy; delete those from a
style if you want draw.io to route an edge freely.

Colours match the documents:

| Meaning | Colour |
|---|---|
| dev / safe / pass | `#15803D` green |
| stage / caution | `#B45309` amber |
| prod / blocked / danger | `#B91C1C` red |
| GitHub / informational | `#1D4ED8` blue |
| Proxmox host | `#6D28D9` purple |
| Management / state | `#0F766E` teal |

## Regenerating from source

Both files are generated by scripts rather than drawn by hand, so a structural change is easier to
make in the generator than in the editor. The generators live outside this repository; if you need
them, the diagrams are simple enough to edit directly in draw.io instead.
